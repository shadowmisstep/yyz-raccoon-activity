# yyz-raccoon-activity
This project examines the Toronto Raccoon Activity Index, an April Fools joke published by Open Data Toronto in 2026, and attempts to approach the dataset as both a genuine record of raccoon activity, as well as how generated datasets may reflect and codify existing assumptions about urban spaces, the environment, and "pest" species.

# File Structure
The repository is structured as follows:
- The `data` folder contains all the data used in this paper. This includes example simulated data, the raw data as downloaded from the Open Toronto Data Portal, and any cleaning, processing and statistical analysis, saved as independent `.csv` files.
- The `paper` folder contains the final PDF version of the manuscript, the Quatro Markdown version of the manuscript, and a copy of the bibliography in LaTeX format.
- The `scripts` folder contains the R code used to simulate, obtain, clean, process, analyse, and visualise the data.
